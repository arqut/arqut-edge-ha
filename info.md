# Arqut Edge Integration

Integrate your **Home Assistant** automations with the **Arqut Edge v0.7.0+ Event Log** ecosystem. 

This integration eliminates the need for managing cumbersome `rest_command` blocks or editing `configuration.yaml` files manually. 

## Key Highlights

* **100% UI Configurable:** Set up your connection and API Key directly via Home Assistant's Integration Dashboard.
* **Proactive Monitoring:** Instantly route critical smart home status updates, security triggers, or server sensor parameters to your phone.
* **Rich Notifications:** Supports passing raw text payloads, dynamic states, and specialized event filtering states (`notification`, `security`, etc.).

## Quick Setup Reminder

1. Download this integration via HACS.
2. Restart Home Assistant.
3. Navigate to **Settings** -> **Devices & Services** -> **Add Integration**.
4. Search for **Arqut Edge** and paste your API Key.
